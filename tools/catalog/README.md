# أداة الكتالوج — مراجعة المنتجات منتجاً منتجاً (TASK-0304 · المالك seq 340/343/344)

1. `node amz.js search "<الموديل>"` — أوّل 10 نتائج في أمازون (متصفّح حقيقي؛ curl يُحجب).
2. `CAT_DIR=… ./pick.sh <ASIN> <tag> [صور] [بوسترات]` — صفحة المنتج: العنوان والنقاط والمواصفات + تنزيل الصور ولوحة تلامس `p/<tag>.jpg`.
3. **تُراجَع اللوحة بالعين** — تُستبعد صور سعةٍ/نسخةٍ أخرى أو كومبو أو إعلان منتجٍ آخر. لا صورة بلا تطابق مؤكَّد.
4. `U=… K=… python3 -I apply.py job.json` — يرفع الصور إلى `products-images/catalog/<id>/` ويُلحقها بعد صور المنتج (لا حذف) · يضيف المواصفات الناقصة فقط · `__desc` يُستبدل إن كان أطول · أسماء بديلة · توافق إن كان فارغاً · سطر `gmt_audit` (`catalog_enrich`).
5. `sync.sql` (عبر أداة SQL · `__IDS__` = المعرّفات) — يزامن الصور والوصف والمواصفات والتوافق إلى قوائم المتجر المربوطة (`inv_id`) بنسخة احتياطية، **ولا يكتب إلّا إن بقي عدد المنتجات كما هو**.
- النسخة الاحتياطية قبل البدء: `gmt_catalog_backup` رقم 66 (350 منتجاً بصور 0–2).
