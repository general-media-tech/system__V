# التسليمات بين الجلسات — handoffs/

> الدستور، المادة ٧ و١٣ و١٥. **لا يُحذف ملف تسليم** حتى بعد اكتمال مهمته (المادة ١٤) — يُحدَّث رأسه بالحالة الجديدة فقط.

- `TASK-xxxx.md` — سجل تسليم لكل مهمة توقّفت قبل اكتمالها (انسخ القالب أدناه).
- [`SESSION_LOG.md`](SESSION_LOG.md) — التقرير النهائي لكل جلسة (يُضاف في آخره، لا يُستبدل).

## القالب
```markdown
# تسليم TASK-xxxx — <العنوان>

- **الحالة:** `HANDOFF_READY`   ← أو `BLOCKED`
- **الجلسة السابقة:** session_...        · **تاريخ التسليم:** YYYY-MM-DD HH:MM UTC
- **فرع/التزام آخر نقطة آمنة:** <الفرع> @ <sha> (مدفوع: نعم/لا)
- **القفل:** محرَّر / ما زال محجوزاً (ولماذا)

## الهدف الأصلي
## ما أُنجز فعلاً (مع الدليل)
## الملفات التي تغيّرت
| الملف | ما تغيّر | الحالة: محفوظ ومدفوع / غير محفوظ / يحتاج تحقّقاً |
## الأوامر والاختبارات ونتائجها الفعلية
## الأخطاء المعروفة وسبب التوقّف
## ما يجب عدم تغييره أو تكراره
## الخطوة التالية بالتحديد (الملف · الدالة · السطر إن أمكن)
## شروط اعتبار المهمة مكتملة
```
