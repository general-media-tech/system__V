# حزمة الاختبار الآلي (Playwright + قاعدة وهمية)

تفتح **الصفحات الحقيقية** للمشروع في Chromium مقابل خادم PostgREST وهمي محلي (`mock.py`) — لا تلمس أي قاعدة حقيقية ولا الإنترنت.

## التشغيل
```bash
mkdir -p /tmp/gmt-out
cd /home/user/system__V && python3 -m http.server 8765 --bind 127.0.0.1 &      # الموقع
python3 tests/harness/mock.py 8197 &                                              # القاعدة الوهمية
cd tests/harness && node t_mufti.js                                               # اختبار واحد
```
المنافذ الافتراضية: الموقع `8765`، القاعدة الوهمية `8197` (تُغيَّر بـ `BASE_PORT` و`MOCK_PORT`). مكتبة playwright متوقّعة في `/opt/node22/lib/node_modules/playwright` (تغيير المسار في أول سطر من `h.js`).

## الملفات الأساسية
| الملف | الدور |
|---|---|
| `h.js` | يفتح صفحةً بجلسة أدمن/موظف، يعترض `*.supabase.co` ويحوّله للقاعدة الوهمية، ويحجب كل مضيف خارجي |
| `mock.py` | قاعدة وهمية تحاكي PostgREST: 204 عند عدم تعديل أي صف، أعمدة ناقصة (PGRST204/42703)، قيود فريدة، دوال RPC |
| `syntax.js` | يفحص صياغة كل ملفات JS وكل كتل `<script>` المضمَّنة (≈١٤٦ كتلة) |
| `sweep.js` | مسح شامل: كل صفحة × (موبايل/كمبيوتر) × (أدمن/موظف) — أخطاء JS · طفح أفقي · أزرار عائمة · نوافذ المتصفح الأصلية · ملفات 404 |

## اختبارات هذه الجلسة (١٦ ت١ ٢٠٢٦)
`t_mufti.js` · `t_mufti2.js` (زرّ التحقق/الفرع المُرسِل/كليشة الحوالة/التبليغ المباشر) — `t_custcache.js` (أسماء الزبائن بلا إنترنت) — `t_invoice_tpl.js` (قالب الفاتورة المشترك) — `t_comments.js` (تكيّف عمود التقييمات) — `t_warranty.js` (كرت الكفالة وسلسلة الشعار وصفحة PDF واحدة) — `t_receipt.js` · `t_receipt2.js` · `t_receipt3.js` (قراءة رقم التتبّع من صورة الإيصال).

> بقية ملفات `t_*.js` اختباراتُ الجلسات السابقة (المال والمحاسبة ونقطة البيع والأدمن والجرد…). راجع `docs/سجل_الاختبارات.md`.
> بعض الاختبارات القديمة تُشفّر سلوكاً قديماً غُيّر عمداً؛ إن فشل اختبارٌ قديم فتحقّق أوّلاً هل هو السلوك المتعمَّد قبل «إصلاح» الكود.
