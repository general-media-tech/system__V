# دليل دمج منظومة الأصوات v3 وتقريرها (OWN-09#65 · #66)

> المحرّك: `gmt-sound.js` (يُحمَّل على كل صفحة داخلية) · الاسم العام `GMTAudio` (والاسم القديم `GMTSound` يبقى مستعاراً) · المعرض: `home.html?sounds=1`.

## ١) التقرير المختصر
- **99 صوتاً** مركَّباً بلا ملفات صوتية، في 8 فئات مستعملة: الواجهة 47 · العملاء والمالية 13 · النظام 11 · الأمان 10 · المزامنة 7 · الضمان 6 · الطلبات 3 · الكاشير 2.
- **48 حدثاً** في جدول الربط المركزي `GMT_EVENT_MAP` (الحدث ⇐ مفتاح الصوت + التأثير البصري).
- كل صوت = **صوت + اهتزاز + تأثير بصري** من محرّك واحد؛ الإعدادات تُحفظ في `localStorage` (مستوى الصوت · الملف الصوتي · فئات مُطفأة · تفضيلات التأثير).
- الحماية: Limiter يمنع القصّ · فترة تهدئة لكل مفتاح · تنويع طفيف (detune) للمتكرّر · هرمية جهارة (الأمان والمال أعلى من النقرات) · احترام `prefers-reduced-motion`.

## ٢) الدمج في أيّ صفحة
```html
<script src="gmt-sound.js"></script>   <!-- المحرّك: يركّب زرّ الصوت ويلفّ showToast/النقر تلقائياً -->
```
بلا أيّ سطرٍ آخر تعمل: النقرات العامة · الرسائل (toast) · النماذج (خطأ تحقّق/نجاح/Enter) · أخطاء الصفحة غير المتوقّعة (مرّة كل ثانيتين) · **فتح/إغلاق المودالات** (`.modal-overlay` · `[role=dialog]` · `<dialog>` · `[id$=Modal]`).

## ٣) الاستعمال من الكود
| الغرض | السطر |
|---|---|
| صوتٌ مباشر | `GMTAudio.play('success')` |
| حدثٌ من الجدول المركزي | `GMTAudio.emit('order.created', { el })` |
| صوت + اهتزاز + حركة على عنصر | `GMTAudio.fire('error', { el })` |
| مستوى الصوت · كتم | `setVolume(0.5)` · `mute()` · `unmute()` |
| الملف الصوتي | `setProfile('quiet')` |
| إطفاء فئة | `toggleCategory('UI', false)` |
| تأثير بصري وحده | `GMTAudio.fx('shake', el)` |
| تصدير جدول الربط | `GMTAudio.exportMap()` (أو زرّ التصدير في المعرض) |

## ٤) بالسمات في HTML (بلا JavaScript)
- `data-sound="success"` على أيّ زرّ ⇒ صوته الخاص بدل نقرة الواجهة (ويتغلّب عليها فلا يُسمَع صوتان).
- `data-sound="none"` أو `data-nosound` على العنصر/أبيه ⇒ صمت.
- `data-fx="shake flash-red"` ⇒ التأثير البصري المرافق.
- `data-snd-watch="order.created"` على حاوية قائمة ⇒ كلّ عنصر جديد يُضاف إليها يُصدر ذلك الحدث (مرة لكل دفعة).

## ٥) تعديل الربط بلا لمس المحرّك
عرّف `window.GMT_EVENT_MAP = { 'invoice.paid': { key: 'success', fx: 'flash-green' } }` **قبل** تحميل `gmt-sound.js` (أو أضف لاحقاً) فتتغلّب قيمك على الافتراضيات.

## ٦) أحداث المزامنة
`gmt-sync.js` يبثّ `gmt-sync-pending` (حُفظت محلياً بانتظار الاتصال) · `gmt-sync-retry` · `gmt-sync-fail` ⇒ تُسمَع بأصوات SYNC_PENDING/RETRY/FAIL.
