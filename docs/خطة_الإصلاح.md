# خطة الإصلاح والعمل القادم

آخر تحديث: 2026-10-17

## ١) قيد التنفيذ الآن (دفعة واحدة، أربعة مسارات منفصلة الملفّات + مراجعتان مستقلّتان لكل مسار)
| المسار | البنود |
|---|---|
| الأوردرات | صورة/PDF داخلي بعربية سليمة + مشاركة بلا طباعة · الحذف بصلاحية سيادية · مكان قفل الأوردرات · نموذج اللصق · واجهة الكمبيوتر |
| السجلّ والجلسة | سجل عمليات مقروء بفلاتر ونسبة لكل نقطة بيع · جلسة أدمن دائمة (تذكّر الجهاز) · إصلاح «شو الجديد» وشاراته · أزرار الرجوع |
| الجرد والمنتجات | التحديد الجماعي من نفس الشاشة · أداتان واضحتان (إدارة/جرد) · فرز المنتجات القديمة · «ما يطلبه الزبائن» |
| الكفالة | واجهة كمبيوتر لإنشاء الكفالة · نوافذ النظام بدل نوافذ المتصفح · الأصوات |

كل مسار يُختبر بتشغيل الصفحات الحقيقية (هاتف 390px وكمبيوتر 1366px)، ثم يراجعه مراجعان مستقلّان يحاولان كسره، ثم يُدمج ويُشغَّل المسح الشامل قبل النشر.

## ٢) بعدها مباشرةً
1. تعميم الحذف بصلاحية سيادية على بقية الصفحات (نقطة البيع، المشتريات، الجرد، المتجر/الموقع، الأمان، سلّة المحذوفات).
2. توليد QR محلّياً في الفواتير (K-06).
3. خطّ عربي محلّي لنوافذ الطباعة (K-07).
4. استكمال اختبارات المسارات المالية المتبقية (M-02).
