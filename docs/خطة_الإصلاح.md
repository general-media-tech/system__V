# خطة الإصلاح والعمل القادم

آخر تحديث: 2026-10-17

## ٠) 🔴 حادثة البوت — 17 ت1 (أولوية قصوى)
**ما حدث:** شخصٌ غريب سيطر على بوت تيليغرام (غيّر اسمه وشغّله لصالحه) فحذفته تيليغرام. **السبب:** مفتاح البوت كان مكتوباً في ٧ ملفّات من المستودع العامّ، فأيّ أحدٍ يقرأ المستودع يملك البوت. ولهذا أيضاً «وقف بوت الأوردرات».

**ما صار جاهزاً في هذا التحديث (لا يحتاج منك تعديل أي ملفّ):**
1. حُذف مفتاح البوت من كل الملفّات؛ الصفحات تكتب علامة «gmt-relay» لا قيمة لها.
2. كل تبليغ تيليغرام (الأوردرات · نقاط البيع · الأدمن · الجرد · الكفالات · المتجر · إشعار الحساب الجديد · تقارير العقل) يمرّ بالوسيط `gmt-tg` في Supabase، والمفتاح **سرٌّ هناك فقط**.
3. الوسيط محصَّن: يرسل لقنوات النظام الأربع فقط · لا يسمح بتغيير اسم البوت ولا ربطه بخادمٍ آخر ولا قراءة رسائله · الحذف فقط لرسالةٍ مربوطة بأوردر · حدٌّ لعدد الطلبات وحجمها.
4. مفتاح JSONBin (نسخة احتياطيّة لطلبات المتجر فيها أسماء الزبائن وهواتفهم وعناوينهم) كان مكشوفاً أيضاً ⇒ صار في الوسيط.
5. «عقل النظام»: مفاتيح Gemini/Claude كانت أصلاً أسراراً على الخادم (لم تكن في الصفحات)؛ أُضيف شرط نطاق الموقع وحدٌّ للطلبات كي لا يستنزف أحدٌ الرصيد.
6. فحصٌ آلي (`tests/harness/t_tgrelay.js`) يفشل إن رجع أيّ مفتاح بوت أو JSONBin إلى أي ملفّ.

**المطلوب منك بالترتيب (١٠ دقائق):**
1. افتح @BotFather ← `/newbot` ← اختر اسماً ومعرّفاً ← انسخ المفتاح. **لا ترسله بواتساب ولا تصوّره ولا تكتبه في أي ملفّ.**
2. أضف البوت الجديد **مشرفاً** (نشر الرسائل + حذف الرسائل) في المحادثات الأربع التي يستعملها النظام: قناة الأدمن ونقاط البيع والجرد · قناة الأوردرات · قناة طلبات المتجر · مجموعة الكفالات (المعرّفات في ملفّ التسليم الخاص).
3. ثم في BotFather: `/setjoingroups` ← Disable (لا يضيفه أحدٌ لمجموعات أخرى).
4. Supabase ← مشروع **Inv excel** ← Edge Functions ← **Secrets** ← أضف `TG_BOT_TOKEN` = المفتاح. انتهى — كل الصفحات تعمل فوراً بلا تحديث.
5. JSONBin: من jsonbin.io ← API Keys **أعد توليد** المفتاح الرئيسي (القديم مكشوف). إن أردت إبقاء النسخة الاحتياطيّة ضع الجديد سرّاً `JSONBIN_MASTER_KEY` بنفس المكان؛ وإن لم تُرده فلا تضعه (الطلبات محفوظة في القاعدة أصلاً).
6. العقل: إن كان أيّ مفتاح Gemini/Claude قد نُسخ يوماً في محادثة أو لقطة شاشة فدوّره من لوحة المزوّد وضع الجديد مكانه في الأسرار، وراجع الاستهلاك.
7. جرّب: أنشئ أوردراً تجريبياً ⇒ تصل رسالته لقناة الأوردرات.
8. (يُستحسن) GitHub ← Settings ← Code security ← فعّل Secret scanning و Push protection.

**ما يبقى بعدها:** الوسيط يقبل أي طلبٍ يحمل مفتاح القاعدة العامّ (وهو منشور بطبيعته) ⇒ أقصى ما يستطيعه غريب: رسائل محدودة العدد إلى قنواتنا فقط. الحلّ الجذري تسجيلُ دخولٍ حقيقي (Supabase Auth) — ضمن خطة الأمان الكاملة. وبوت «بثّ العروض» الذي يُدخَل مفتاحه يدوياً على جهازك لم يُنقل بعد (ليس في المستودع).
