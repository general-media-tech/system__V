## الجداول الخاصّة في القاعدة الرئيسية
- **`gmt_catalog_backup`**: نسخة احتياطية قبل أيّ تعديل. لا تُحذف.
  - الصفّ 1 = منتجات الجرد كاملة.
  - الصفّ 2 = سجلّ المتجر كاملاً.
- **`gmt_catalog_audit`**: سجلّ تدقيق لكلّ منتج، فريدٌ بـ `(source, source_id)`. الحقول:
  - `snapshot` · `facts` · `issues`
  - `match`: الروابط القائمة أو المرشّحون
  - `proposals`: كلّ مقترحٍ بمن كتبه ومتى ودرجة ثقته وسببه
  - `status` ∈ pending · reviewed · needs_owner · done
- **التعديلات الفعلية** تُكتب في `gmt_audit` الموجود: القيمة القديمة والجديدة والسبب.
- **قراءة المتجر من الجلسة:** قاعدة المتجر ليست في أداة Supabase. تُقرأ من القاعدة الرئيسية بـ `http()` والمفتاح العامّ للمتجر الموجود أصلاً في `gmt-config.js`.
