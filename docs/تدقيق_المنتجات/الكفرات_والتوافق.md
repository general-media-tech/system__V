- **في الجرد:** كفرٌ واحد لكل موديل كاميرا، بلا تعريفٍ للألوان. كلّ الكفرات القديمة حمراء (المالك).

- **الصور:** كلّ الكفرات بمجموعة الصور نفسها: الصورة الحمراء الموجودة + صور المالك العشر (`img/products/covers/cover_01..10.jpg`).
