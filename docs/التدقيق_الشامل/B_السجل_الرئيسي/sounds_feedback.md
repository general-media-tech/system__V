## REQ-0533 · إضافة أصوات مع الانتروهات: انترو التتبع (الشاحنة)، فتح المتجر، فتح التطبيق للمستخدمين والموظفين (مثل أمازون برايم/يوتيوب بفقاعة مع اللوجو)، الكفالة، عدادات الموقع وبوابة التوظيف، مع اختيار مجموعة أصوات فخمة ملائمة وفحص أين يمكن إضافة مؤثرات.

- **الموقع:** S02_design_ui_reference.txt · الأسطر 31–31

> (النصّ الحرفي في النسخة الخاصّة — المستودع عامّ؛ الموقع أعلاه)

  - REQ-0533.2 صوت عند فتح المتجر عند انبثاق «أهلاً بكم» أو شعار الشركة
  - REQ-0533.3 صوت عند فتح التطبيق للمستخدمين والموظفين (مثل صوت أمازون برايم أو فتح يوتيوب، صوت فقاعة مع انبثاق اللوجو)
  - REQ-0533.4 صوت عند فتح الكفالة للشخص
  - REQ-0533.5 صوت عدادات عند فتح الموقع الإلكتروني وبوابة التوظيف مع الأرقام المتحركة
  - REQ-0533.6 أصوات للانتروهات الموجودة للمستخدمين
  - REQ-0533.7 تحديد مجموعة أصوات يتلاءم كل منها مع انترو/موقع محدد، والبحث عن أصوات فخمة ومتلائمة مع الوضع
  - REQ-0533.8 فحص أين توجد انتروهات ودخلات يمكن إضافة مؤثرات صوتية لها وإضافتها
